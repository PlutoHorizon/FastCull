# RAW 编辑：本地显影、独立窗口与 XMP

选中 ARW、NEF 或 DNG，点击左侧 **RAW 编辑**，在独立窗口中加载 RAW 和对应 XMP。编辑窗口打开期间锁定主选片器，完成自动保存与回传后恢复操作。独立使用不需要安装或启动 Photoshop、Camera Raw、Lightroom 或 Bridge；显影由随程序提供的 LibRaw 原生模块完成。

当前支持曝光、白平衡、色温、色调，以及 **对比度、高光、阴影、白色、黑色、自然饱和度、饱和度** 七项基础调整。显示目标为 sRGB。与 LR/ACR 的互通通过 XMP 字段实现，本地画面使用自己的显影和色调模型。

当前工作区的 Windows 构建中，主窗口曝光预览及独立 RAW 编辑使用 **DirectX 12**，优先 NVIDIA；macOS 源码使用 **Metal**，两端不回退 OpenGL。先前禁用的入口已恢复，公开 2.9.0 包仍是旧实现，本地修订尚未发布。Windows GPU/窗口已经验收；Mac 目前仅编译、静态及着色器转换检查通过。验证与限制见 [内嵌配置与 Metal 记录](diagnostics/COLOR-EMBEDDED-METAL-2026-11-02.md)。

## 使用

1. 在主窗口选中照片，打开 **RAW 编辑**。先显示文件中的快速预览；有 GPU 且不超过 6000 万像素时，首个 RAW 显影直接准备全尺寸并上传纹理。提示“100% 已就绪”后放大直接复用。大图或全尺寸失败时，先生成适屏图，再按预算后台预加载。
2. 在“色调”和“颜色”分组调整参数。曝光与七项基础滑杆由 GPU 实时显示；白平衡调整会触发后台 RAW 重新处理。顶部 RGB/亮度直方图根据本地 sRGB 预览采样，随调整更新。
3. 白平衡可选“保留原设置”“原片”或“自定义”。自定义色温范围为 2000–50000 K，色调为 -150–150。
4. **灰点吸管**：点击应为中性灰或白、未过曝的区域，获得可继续微调的白平衡估计，再等待本地显影刷新。过暗、剪切或无效样点会提示重新取样。
5. 与选片一致，**单击照片将所点位置居中放大至 100%，再次单击返回适配**；拖动平移，释放拖动不会切换倍率。按 **F** 或 **Z** 也可切换。保留以鼠标为中心的滚轮连续缩放；右侧“查看”可选适屏、100%，或修改百分比（最高 800%）。100% 按原图像素和屏幕物理像素计算；放大后自动加载全尺寸，替换预览时保持倍率与位置。点击“对焦点”按钮或按 **O** 可显示可用的相机对焦记录。裁切模式使用独立的适屏裁切画布。
6. 底部星级控件与主选片器一致，支持 **0–5** 快捷评分；点击 **裁切 T** 进入相同的裁切编辑器。锁图标切换比例锁定，拖角可自动适应横竖比例。
7. 点 **保存调整到 XMP** 可随时提交。关闭窗口时会自动保存评分、显影参数以及当前尚未点“应用”的裁切；取消裁切只撤销这次裁切草稿。等待保存和回传完成后才关闭；失败时保留窗口与草稿，可修正问题后重试。

分组中的“预览”开关临时比较调整前后，不改变保存参数。重新加载 RAW/XMP 会丢弃未保存调整并重新读取文件或 LR 配方。

## 色彩与兼容边界

本地管线现在保留高精度线性相机数据，在浮点 ProPhoto 工作空间应用白点与配置文件，再处理曝光、Look、色调及基础调整，最后转换为 sRGB。中间缓冲和缓存保留负值及大于 1 的高光；不在显影前半段压成 8 位 sRGB。保存编辑仍只修改元数据，不重新编码 RAW 图像数据。

| 内容 | 当前行为 |
| --- | --- |
| 原片白平衡 | 保留相机实际通道增益；界面色温/Tint 从这些增益估算 |
| 自定义白平衡 | 原生和 Rust 共用 Robertson 白点模型，Tint 距离标度为 1/3000 |
| 内嵌及本机 DCP | 支持 DNG 主/附加配置、双光源矩阵插值、前向矩阵、相机校准、Hue/Sat 校正、Look 表、显式曲线及曝光基线偏移；无显式 XMP 选择时优先内嵌 |
| 配置文件选择 | 下拉框列出文件实际内嵌项与已安装的机型匹配 DCP；选择后重新显影，保存到 XMP，重新打开保留选择 |
| Adobe Color | 读取已安装配置中的基础 Adobe Standard DCP、额外 LookTable 和主曲线；通过标准增强 Look 结构保存供 ACR 读取。其他增强配置仍可能回退，实际结果和原因明确显示 |
| 没有可用 DCP | 使用 LibRaw 相机矩阵与本地默认色调，界面提示 |
| 蒙版及其他未知显影设置 | 保留 XMP 和资源，不参与本地画面处理 |

DCP 从本机 Adobe 用户/系统配置文件目录只读查找，也可通过 `FASTCULL_DCP_DIR` 指定搜索目录，或用 `FASTCULL_DCP_PROFILE` 指定与机型匹配的 DCP 文件。程序不分发 Adobe 配置文件；未安装 Adobe 时仍可使用相机矩阵显影或自行提供 DCP。

DNG 没有明确保存的旁车配置选择时，首次编辑默认采用本机 Adobe Color；已保存的配置或自定义 Look 优先。Adobe Color 从 Camera Raw 的 Settings 目录读取，也可用 `FASTCULL_PROFILE_DIR` 指向包含 `Adobe Color.xmp` 的目录。缺少相关资源时不会把基础矩阵渲染标为已执行 Adobe Color。ARW/NEF 通常没有完整内嵌 DCP，下拉框中的 Camera ST、Camera Standard 等属于本机机型匹配资源，只有实际来自照片的项目标注“文件内嵌”。

切换配置会替换旧配置引用、增强 Look 和失效摘要，保留曝光、裁切、评分及其他显影内容。Adobe Color 的色彩表和曲线与基本滑块共同参与实时预览，但不代表复现 ACR 的全部专有算法。

**相同 XMP 参数仍不代表与 Lightroom/ACR 像素等价。** 无显式曲线时使用公开 SDK 经典 SDR 曲线的 1025 个采样；显式 DCP 曲线按其自然 C2 样条求值。七项基础调整仍采用本地模型，尚未复现当前 Lightroom ProcessVersion 的全部算法。Classic DNG 内嵌配置已接入，BigTIFF、三光源和增强 XMP Look 等仍未完整实现。详见 [色彩管线](COLOR-PIPELINE.md)。

灰点吸管从显示处理前的相机采样数据反解白点，不受当前曝光、色调曲线或 Look 影响；逐通道检查过暗和传感器剪切，再对有效邻域平均。它用于中性物体，不能把有色物体当作已知白色。缺少有效原片白平衡时不会把 6500 K / 0 初值报告为相机参数。

处理版本保持原样：旧 PV 5.0/5.7 的曝光使用 `Exposure`，范围 ±4 EV，对比度使用 `Contrast`，范围 -50–100；旧流程不支持映射的高光、阴影、白色、黑色会禁用。现代已识别流程使用 `Exposure2012`、`Contrast2012` 等字段，曝光范围 ±5 EV，七项基础调整通常为 -100–100。自然饱和度和饱和度可跨这些流程使用。无法识别或存在歧义的版本相关编辑会拒绝保存，不自动升级处理版本。

## 从文件、Bridge 或 Lightroom 读取

独立或从 Bridge 打开时，读取同名 `.xmp`；DNG 没有旁车时读取内嵌 XMP，旁车存在时优先使用旁车。原片白平衡没有可用色温/色调时，不凭空补出一组“相机参数”。

从 Lightroom 插件打开时，RAW 窗口可按需取得当前目录中尚未手动保存到磁盘的完整配方。插件使用 ORIGINAL 导出到私有缓存，保留 RAW、XMP 和相对 `.acr` 等资源；这一步需要原来的 Lightroom 会话仍在运行。选片器的本地显影不调用 Photoshop 或 Camera Raw。目录中的配方可完整保留，但画面仍受上面的本地色彩模型边界限制。

同一原片同时选择多个 LR 虚拟副本会报告歧义；请只选择所需副本后重开。修改插件文件后，应在 Lightroom 插件管理器重新载入插件。

## 保存与同步

- **ARW/NEF**：原子保存同名 XMP 旁车，保留其他命名空间及未修改字段。
- **DNG**：先原子保存旁车，再由本地代码把 XMP 写入 DNG 内部，不调用 Adobe。通过同目录临时副本追加 XMP 与新 IFD0，确认后原子替换；原有图像条带、瓦片和其他原始字节保持原位置，不重新编码图像。元数据及文件哈希会改变。
- DNG 内嵌写入对 Classic TIFF 布局进行验证；BigTIFF、超出 32 位偏移范围、损坏目录或只读文件会拒绝更新。旁车已保存而内嵌失败时明确提示，允许重试。

导入 LR 完整配方时只合并显影内容，保留原片星级、标签、旗标及其他非显影元数据；在 RAW 窗口明确修改的星级会随保存写入。需要的相对资源随保存保留；已有同名资源内容不同时停止，不覆盖共享资源。打开后原片或 XMP 被其他操作改动，保存会拒绝覆盖，需重新加载后再编辑。

每次成功保存生成独立回执，主进程按顺序登记星级、裁切、方向、曝光、WB 和实际修改的基础子项。显式 0 是有效重置，未修改项不会顺带同步。LR 同步只更新相应字段，并核对 SDK 读回；仅同步星级不会确认 WB 或基础调整。RAW 编辑期间主窗口锁定；编辑窗口自动保存并确认回执后恢复主窗口。失败回执保留并报告。

LR/ACR 已打开照片时可能保留目录或内存状态。LR 可用插件同步；Bridge/ACR 应重新读取照片元数据。数值互通不保证原编辑器与本地画面一致。

## 性能策略

- 独立进程承载 RAW 窗口，文件读取、显影、图像解码与保存放在后台；普通选片不启动 RAW 编辑器或任何 Adobe 进程。
- 先显示内嵌快速预览；GPU 编辑窗口在原尺寸不超过 6000 万像素时，首次直接生成全尺寸，省去适屏显影与 500 ms 空闲等待的重复流程。配置列表在首次显影请求之后读取。全尺寸首次失败自动回退一次至长边最多 **1600 像素**的适屏图；无 GPU 或超预算仍按适屏路径加载。适屏就绪且空闲后可按预算准备当前一张全尺寸图，保持倍率和位置。准备完的 100% 缩放复用原尺寸纹理；尚未完成时仍有真实加载成本。快速预览可能带有相机或原软件的烘焙色彩，与随后本地显影有差异。
- 曝光与七项基础调整直接由 GPU 处理，不为每次滑杆变化重解 RAW。WB 的 RAW 请求采用 **250 ms 去抖**，松开滑杆后处理；只保留最新排队结果，取消过期处理，旧结果不替换新图。
- 当前一张照片的 RAW 解包缓冲可复用，重复显影不必每次重新 unpack；路径、文件大小或修改时间变化时重建。适屏允许半尺寸解码与较快插值，全尺寸使用更高质量插值。
- 线性浮点缓存使用独立版本命名空间，按照片身份、文件状态、配方和输出尺寸区分，并校验实际 DCP 指纹；旧 8 位预览不会混用。只清理应用标记的缓存，不扫描或删除照片目录。缓存限制和取消机制不消除大 RAW 首次解码及全尺寸处理的成本。
- 灰点吸管使用有界小采样图和邻域平均，不复制整张全尺寸图像，也不在点击事件中同步执行 RAW 显影。
- WB 拖动先以 GPU 临时预览响应，随后用完整显影校正；原始解码以单张、最多 512 MiB 的不可变共享 RGB 缓存复用。全尺寸调整不再逐次同步写入大型浮点磁盘缓存，适屏缓存继续保存；重新打开后的全尺寸可能需要重新显影。Windows 原生插值默认最多使用 4 个 OpenMP 线程，运行库随插件携带。
- 内嵌快速预览先于配置列表发布；相机矩阵、HSV 映射、面积缩放及彩噪处理最多使用 8 个 CPU 行工作线程。已解析的 DCP、内嵌配置及 Adobe Color 按路径、大小和修改时间复用；配置修改后重新解析。曝光滑杆的范围在配方变更时更新，绘制界面时不重复解析整个 XMP。
- 本地显影在线性相机 RGB 阶段抑制彩噪，保持每个像素的相机 RGB 加权亮度，按亮度和颜色边缘限制邻域混合；全尺寸按分辨率扩大处理范围，避免只在适屏时有效。读取 `crs:ColorNoiseReduction`（0–100），缺省按 25 处理，显式 0 关闭；此为本地近似，不是 Adobe 降噪算法。该读取不会改写旁车的降噪参数。旧版浮点预览通过管线版本失效，不继续显示未降噪缓存。
- Windows/macOS 的 400 万像素以上彩噪任务可复用预览 GPU 执行 float32 计算；适屏小图保留 CPU，避免首次初始化和传输开销。GPU 分块处理并携带邻域，全部成功后才提交；不可用时回退 CPU。开发对照可设 `FASTCULL_RAW_COMPUTE=cpu` 强制参考路径。

常规 Bayer 全尺寸 AHD 通过 GPU 回调执行，保留原算法与浮点舍入；其他传感器/插值模式继续使用 LibRaw。Sony 四分量瓦片与三通道线性 DNG 的 SOF3/预测器 1 无损 JPEG，可将 Huffman 熵解码和预测重建放到 GPU；TIFF/JPEG 头解析、码流去转义与瓦片拼接仍在 CPU。只支持无重启间隔、无点变换的完整扫描，不支持的文件及计算失败回退 LibRaw。NEF 等其他压缩路径保留 CPU。8 个及以上可用逻辑处理器默认使用实测更快的最多 8 线程瓦片解码，较少处理器默认尝试 GPU；这是当前调度策略，并非所有硬件的自动性能标定。可设 `FASTCULL_RAW_ENTROPY=gpu` 强制 GPU、`parallel` 强制并行瓦片 CPU、`cpu` 恢复原 LibRaw 熵路径；`FASTCULL_RAW_COMPUTE=cpu` 则关闭全部 GPU RAW 计算。只读映射仍仅作为开发对照。新代次会取消旧任务，保存可抢占，失败不提交部分图像。

## 验证记录

2026-10-30 色彩校准采用无窗口数值验证，三格式固定白平衡样本、缓存浮点往返、曝光单调性及灰点求解结果见 [色彩校准验证](raw-color-calibration-validation-2026-10-30.json)。2026-11-02 又完成 DirectX 真机 GPU 像素对照、三格式原生窗口和主窗口曝光/对比检查，详见 [迁移记录](diagnostics/RAW-DIRECTX-2026-11-02.md)；不代表已在真实 Lightroom 宿主验证色彩或同步全流程。

早期本地引擎、独立窗口及七项控制的验收记录见 [raw-window-validation-2026-10-24.json](raw-window-validation-2026-10-24.json)。本次并行加载、父窗口锁定、RAW 评分与裁切、退出自动保存的结果见 [2026-10-30 RAW 工作流验证](raw-flow-validation-2026-10-30.json)。批量性能数字仅代表报告中记录的本机样本与受控消费节奏。

[raw-edit-validation-2026-10-24.json](raw-edit-validation-2026-10-24.json) 记录的是此前 **Photoshop/Camera Raw 后端**的历史验证。该报告中的 Adobe 显影耗时、颜色表现和宿主测试不能用于证明当前 LibRaw/GPU 后端的性能或像素等价。

LR 配方导出、同步和回执的 SDK 模拟测试用于检验数据合同，不代表已经在真实 Lightroom 目录中完成所有版本、虚拟副本和蒙版类型的端到端验证。Windows 以当前本机构建验收为准；macOS 的原生模块与窗口行为仍须单独实机验证。

首次全尺寸又减少了浮点转换、重复内存遍历和着色器串行编译，并将符合条件的相机颜色表延迟至 GPU 的源像素采样阶段；不是在缩放后的像素上改色。开发对照可设 `FASTCULL_RAW_HSM=cpu`；Windows/Metal 以外及不支持的表继续使用 CPU。

Windows 已增加会话内 RAW 进程/设备复用，以及原生相机 RGB 后的 GPU 常驻降噪、几何与色彩矩阵。照片关闭时释放照片缓存，主选片器关闭时自动保存回传并退出。CPU 导出先显式物化常驻帧；GPU 不支持时回退。
